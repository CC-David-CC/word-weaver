# Word Weaver

Spell, decode, and weave vocabulary words using letter tiles, contextual definitions, and phonetic hints across 8 challenges.

![Gameplay in a desktop WebOS window](docs/desktop.png)

[Phone view](docs/phone.png) · [Game rules](docs/CORE-RULES.md)

The release candidate opened from Games → Learning & Strategy. The browser check played a turn and closed the window on phone, 1080p and 4K layouts. These screenshots show synthetic gameplay.

Run the native suite in the WebOS npm workspace with `node --test tests/*.test.mjs` from this directory.

Use **Game files → Save** to keep a round as `.word-weaver.json`. Open that file from WebOS Files to continue playing. Anon files last for this browser tab. Register before leaving to keep them in your account.
